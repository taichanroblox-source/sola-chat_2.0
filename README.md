# SOLA CHAT 2.0 — フルスクリーン・通知・オンライン版

このZIPは前回の承認制7機能版をベースにした完全なプロジェクト一式。

## 主な変更
- 8文字の英数字グループID（既存グループにも自動で付与、内部数値IDは維持）
- グループ参加はID入力→承認制のみ
- 夕焼けの新アプリアイコン、タップでホームに戻る
- 2人/グループのチャット画面は全画面表示、ダッシュボードなし
- 通知センター：種類別タブ、未読数、個別既読、全件既読、関連画面への移動
- オンライン表示：2分以内のアクセスをオンラインと判定。検索・友だち・プロフィールに表示
- これまでの返信、リアクション、写真、未読、ピン、グループ管理、プロフィール画像、通報などを維持

## 起動
```sh
cd ~/Desktop
cp -R SOLA-CHAT-2 "SOLA-CHAT-2-BACKUP-$(date +%Y%m%d-%H%M%S)"
unzip -o ~/Downloads/SOLA-CHAT-2-FULL-REBUILD.zip
cd SOLA-CHAT-2
source .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

Neonを使うときは従来と同じDATABASE_URL環境変数を渡す。既存sola2_テーブルを削除しない。

**注意**: オンライン表示は30秒間隔の通信に基づく推定。アプリを閉じた直後も最大2分オンライン扱いになることがある。
