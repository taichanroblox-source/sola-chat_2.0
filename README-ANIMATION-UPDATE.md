# SOLA CHAT 2.0 — 視認性・リアクション・アニメーション改善

## 更新内容
- チャット操作ボタンの文字を濃くして背景とのコントラストを改善
- リアクションの絵文字選択パレットをメッセージに重ねて表示（チャットの幅や高さを変えない）
- リアクションを押したときの浮遊アニメーション
- メッセージ表示・通知カード・ボタンの自然なアニメーション
- 4秒ごとの更新でメッセージが変わっていない場合はDOMを作り直さない（開いている絵文字パレットを維持）
- 動きを減らすOS設定を尊重

## 適用方法
1. Flaskを止める
2. SOLA-CHAT-2フォルダをバックアップする
3. ZIPをデスクトップで展開して既存の SOLA-CHAT-2 に上書きする
4. Flaskを再起動し、ブラウザで Command + Shift + R

このZIPは `static/app.js` と `static/style.css` だけを変更。Python・Neon・SQLite・既存メッセージには触れない。
ベースは SOLA-CHAT-2-FULL-REBUILD.zip。ブラウザでの実動作確認は未実施。
