# SOLA CHAT 2.0 — 11機能アップデート

このZIPは `SOLA-CHAT-2/` 以下のコードを更新するフルコード版です。**既存のDBファイル、Neonデータ、`.sola2_secret`、`.env` をZIPに含めません。** データベースを削除する処理はありません。起動時に不足しているテーブルと列だけ追加します。

## 追加機能

1. 下書き自動保存：ブラウザのlocalStorageにユーザー・チャットごとに保存。送信したら削除。**別の端末とは同期しません**。
2. グループアイコン：管理者がJPEG/PNG/WebPをアップロード（2MB以下、正方形に加工）。DBに保存。
3. 共同管理者：作成者が任命/解除。参加申請の承認、メンバーの退出操作、説明文やお知らせ編集が可能。所有権の移譲と共同管理者の任命は作成者だけ。
4. 画面内通知：10秒ごとに新しい通知を確認して画面右上に表示。**ブラウザを閉じている間のプッシュ通知ではありません**。
5. 吹き出しの色：マイページで5色から選択。ブラウザごとの設定で、自分の吹き出しの色だけ変更。
6. 画像ギャラリー：チャット内で送信された写真を最大150件表示。
7. グループお知らせ：グループ管理画面から編集、チャット上部に表示。更新時に参加者へ通知。
8. メンバー検索：グループ管理画面で参加者の名前を部分一致検索。
9. オンライン公開設定：マイページから非公開にでき、ほかのユーザーにはオフラインと表示。
10. ニックネーム設定：フレンドのプロフィールから変更。自分にだけ見える名前。2人チャットのタイトルにも反映。
11. ファイル送信：PDF、TXT、CSV、MD、DOCX、XLSX、PPTX。2MB以下。チャット参加者のみダウンロード可能。DBに保存。

## Macへのインストール

1. 起動中のFlaskを `Control+C` で停止。
2. ZIPを `~/Downloads/` に保存。
3. 次をターミナルで実行：

```bash
cd ~/Desktop
cp -R SOLA-CHAT-2 "SOLA-CHAT-2-BACKUP-$(date +%Y%m%d-%H%M%S)"
unzip -o ~/Downloads/SOLA-CHAT-2-11-FEATURES.zip
cd SOLA-CHAT-2
source .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

4. ブラウザで `http://127.0.0.1:5000` を開き `Command+Shift+R` で再読み込み。

### Neonについて

既存の `DATABASE_URL` 環境変数が必要です。Neon側も作業前にバックアップ（またはブランチ）を作成してください。データを削除しない追加型のマイグレーションですが、**実際のNeonへの接続テストは未実施**です。
